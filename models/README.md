# AI mask model

`rvm_mobilenetv3_fp32.onnx` is Robust Video Matting (MobileNetV3, fp32) by Shanchuan Lin, Linjie Yang, Imran Saleemi
and Soumyadip Sengupta, from the v1.0.0 release of https://github.com/PeterL1n/RobustVideoMatting, used unchanged.
It is licensed under the GNU GPL v3.0, which is why LumaTRX as a whole is GPL-3.0.

`u2netp.onnx` is U-2-Net small (U²-Netp) by Xuebin Qin, Zichen Zhang, Chenyang Huang, Masood Dehghan, Osmar R. Zaiane
and Martin Jagersand (https://github.com/xuebinqin/U-2-Net, Apache License 2.0), in the ONNX form published by the
rembg project (https://github.com/danielgatis/rembg, release v0.0.0), used unchanged. It makes the *Subject* AI mask.
